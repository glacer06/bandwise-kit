# @bandwise/core

The Bandwise question set spec format, lints and run engine. Pure TypeScript with no I/O: contracts (zod), the spec compiler, the stage runner, the confidence router, and cost and savings math.

Bandwise is an independent product built on TypeSafe's System One models.

```sh
npm install @bandwise/core
```

Documentation: https://docs.bandwise.dev. Source, examples and the template list: https://github.com/glacer06/bandwise-kit.
