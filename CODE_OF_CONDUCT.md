# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good intent, and keep discussion about the work. Harassment of any kind is not accepted in issues, pull requests, discussions or any other project space.

To report a problem with someone's conduct, contact the maintainers privately through the **Security** tab's private reporting form, or by a direct message to a maintainer on GitHub. Reports are kept confidential. Maintainers may remove comments, close threads or block accounts that break these rules.
